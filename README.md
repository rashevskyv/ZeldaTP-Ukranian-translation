# The Legend of Zelda: Twilight Princess (GameCube і Wii) — патчер українського перекладу

Патчер завантажує з цього репозиторію актуальні файли перекладу і вписує їх у копію вашого образу гри.
Ваш дамп патчер лише читає і не змінює. Підтримуються:

- GameCube, США (`GZ2E01`): `.iso`, `.rvz`, `.gcz`, `.wia`, `.ciso`;
- Wii, США (`RZDE01`): `.iso` або `.rvz`.

Результат для обох версій — один файл `_UA.iso`: його можна запускати в Dolphin і на консолі.

## Вимоги

1. Власний дамп гри (ID і ревізія, як вказано вище).
2. Вільне місце на диску: для GameCube близько 5 ГБ, для Wii близько 15 ГБ (патчер перевіряє це перед запуском).
3. Інтернет для завантаження файлів перекладу.
4. Windows: `TwilightPrincess_Patcher.exe`. macOS / Linux: Python 3.14+ і `python3 patcher.py`.

## Покрокова інструкція

1. Покладіть образ гри в теку `ISO` поруч із патчером.
2. Запустіть `TwilightPrincess_Patcher.exe`.
3. Патчер сам визначить, GameCube це чи Wii. Якщо в теці кілька образів, оберіть номер.
4. Результат з'явиться поруч з оригіналом: `<назва>_UA.iso`.
